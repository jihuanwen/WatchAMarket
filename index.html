交易时段 5 秒刷新；休市 / 周末暂停自动刷新（点「刷新」整页重载、获取最新版本）。
顶部「大盘强度 / 板块强度 / 题材热度」为可折叠分组，点击标题展开收起；大盘强度分「主板 / 双创」两块（主板＝上证指数+沪深300，双创＝创业板指+科创50），各按「组内指数动量40 + 行业宽度30 + 趋势30」打分，并给出各自压力位 / 支撑位（取现价上方/下方最近的均线与20日高低）。板块强度分「主力资金净流入榜（前5）/净流出榜（前3，点击板块展开成分股涨幅前5前排票）」「申万行业涨幅榜 / 领跌（默认收起，点击展开）」「今日涨停板」。
「题材热度」分组显示「前三题材板块的涨停板（龙头+中军+涨停梯队，点击板块行展开跟涨票）+ 涨停梯队折叠按钮（底部）」。板块与资金流为 AI 维护的热门列表（仅观察参考，非买入指令）。
「开盘至今」识别高开低走 / 低开高走；「超额」= 个股涨跌幅 − 沪指涨跌幅。
每只「关键位」为 AI 按最新收盘技术形态自动给出的操作建议，可在底部「更多 → 成本&关键位」里修改，留空则恢复默认。
点持仓行（除 ×）弹出「胜率模型」+「仓位决策」；仓位决策按六因子（趋势25·MACD20·KDJ15·RSI10·量能15·区间位置15）加权出综合分(0-100)与置信分，给出加仓 / 锁仓 / 减仓 / 清仓四档建议。持仓行已直接显示决策徽章（动作+置信+综合）与关键价位：加仓参考 / 减仓参考 / 止损参考，无需点开弹窗；点持仓行看六因子明细与操作纪律。
模型方案可在底部「更多」切换：模型A＝AI 启发式（量能+均线+MACD+形态打分），模型B＝自定义（规则待提供）。点行尾 × 移除（持仓只存本机，不上传）。
添加到主屏幕：Safari 点分享 → 添加到主屏幕；Chrome 菜单 → 添加到主屏幕。之后可像 App 全屏打开。
